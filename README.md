# 에디톨로지 · 생각을 편집하는 메모장

> "창조는 편집이다. 자기만의 방식으로 편집할 수 있어야 자기만의 개념이 생긴다." — 김정운, 『에디톨로지』

생각의 조각을 **모으고 · 잇고 · 편집해** 자기만의 개념을 만드는 개인 메모장. 설치·서버·로그인 없이 브라우저만으로 24시간 동작하는 자립형 웹앱(PWA).

## 🔗 바로 쓰기

### 📱 폰에 "앱처럼" 설치하기
- **아이폰(Safari)**: 위 주소 열기 → 하단 **공유 버튼(⬆️)** → **"홈 화면에 추가"**
- **안드로이드(Chrome)**: 위 주소 열기 → 우측 상단 **⋮** → **"앱 설치"** 또는 **"홈 화면에 추가"**
- **PC(Chrome/Edge)**: 주소창 오른쪽 **설치 아이콘(⊕)** 클릭

설치하면 홈 화면 아이콘으로 앱처럼 열리고, 인터넷이 없어도 열립니다.

## 기능
- **카드 메모** + `[[` 입력 시 카드 제목 **자동완성**(없으면 즉석 생성)
- **연관 발견(See Also)** — 태그·내용이 비슷한 카드를 자동 추천
- **세렌디피티** — 약하게 연관된 두 카드를 던져 "다리 놓기" 유도
- **연결 지도** — 카드 연결망 시각화(실선=링크, 점선=내용 유사, 점선 빈 원=아직 안 이어진 **고아 카드**)
- **개념 편집** — 여러 카드를 재료로 모아 새 개념으로 합성
- **휴지통**(복원 가능) · **핀 고정** · **정렬**(수정/작성/제목/연결순)
- **자동 태그 추천** · **이미지 첨부**(붙여넣기·드래그) · **체크박스 할일** · **URL 자동 링크**
- **라이트/다크 테마** 토글

## 데이터 보관
- 노트는 **이 브라우저 안에** 저장됩니다(localStorage). 기기/브라우저마다 별도로 보관됩니다.
- **백업**: 좌측 상단 **내보내기** → `.json` 파일 저장. **가져오기**로 복원·병합.
- Chrome 계열이면 **파일 연결**로 원하는 `.json` 파일에 실시간 자동저장도 가능합니다.
